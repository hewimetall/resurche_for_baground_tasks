# Матрица: библиотека × требование

Версии, которые стояли в стенде: simple-q `1.0.0rc7`, Dramatiq `2.2.1` (пакет `dramatiq-abort` `1.2.1` установлен, в адаптер не подключён), Celery `5.7.0`, arq `0.28.0` (отдельный venv, `redis` `5.3.1`), taskiq `0.13.0` + taskiq-redis `1.2.4` (`redis` `8.1.0`). Шкала измерений — `BENCH_SCALE=short`. «Измерено» значит, что цифра есть в `results/<lib>/<сценарий>.json`. Остальное прочитано в адаптере и в документации библиотеки.

Обозначения: **нативно**, **конфигурация**, **свой код** (оценка строк поверх адаптера), **нет** — в этой версии так не сделать.
